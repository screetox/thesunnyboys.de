A group website featuring music-related content, event info, and media.

## 📝 About

**thesunnyboys.de** is the online home of *The Sunnyboys* — a place to explore their music, find upcoming events, and connect with the band.

## 📂 Planned Features

- 🎵 **Music** – Listen to tracks, albums, and live recordings
- 📅 **Events** – Information about concerts and performances
- 📸 **Media** – Photo galleries, videos, and behind-the-scenes content
- 📢 **News** – Announcements, updates, and special releases

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/screetox/thesunnyboys.de.git
   ```
2. Open the [`index.html`](/index.html) file in a web browser.
